# Журнал группы

Электронный журнал учителя без бэкенда: статический сайт для GitHub Pages.

- `index.html`: разметка двух разделов («Ученики» и «Выставить оценку»)
- `style.css`: оформление (светлая и тёмная тема, адаптивная вёрстка)
- `script.js`: логика на чистом JavaScript
- `data.json`: исходные данные (группа, предметы, ученики, оценки)

## Запуск

**GitHub Pages:** Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`.

**Локально:** `fetch()` не читает файлы со страниц, открытых через `file://`, поэтому нужен сервер:

```bash
python -m http.server 8000
# откройте http://localhost:8000
```

Если открыть `index.html` двойным щелчком, журнал покажет подсказку и предложит выбрать `data.json` вручную.

## Где хранятся оценки

GitHub Pages не позволяет браузеру записывать файлы на сервер, поэтому:

1. При открытии журнал читает `data.json`.
2. Новые и удалённые оценки хранятся в `localStorage` как «слой изменений» поверх `data.json`. Этот слой важнее файла, поэтому после обновления страницы ничего не пропадает.
3. Полоса под шапкой показывает, сколько изменений есть только в этом браузере.
4. **Экспортировать JSON** скачивает полный `data.json` со всеми изменениями. Замените им файл в репозитории. При следующей загрузке журнал увидит, что изменения уже в файле, и очистит слой сам.
5. **Загрузить JSON** открывает журнал из выбранного файла (например, с другого компьютера).
6. **Сбросить к data.json** удаляет локальные изменения.

## Формат data.json

```json
{
  "group": { "name": "10 группа", "year": "2026/2027" },
  "subjects": [{ "id": "math", "name": "Математика" }],
  "students": [
    {
      "id": "st01",
      "name": "Фамилия Имя Отчество",
      "grades": {
        "math": [{ "id": "st01-math-1", "value": 5, "date": "2026-09-10", "comment": "Контрольная" }]
      }
    }
  ]
}
```

Чтобы добавить предмет или ученика, допишите его в соответствующий список. Поля `id` у оценок и `comment` необязательны.
